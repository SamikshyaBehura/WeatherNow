# 🌦️ WeatherNow

WeatherNow is a responsive weather dashboard that displays current weather, hourly forecasts, and a 5-day forecast.

## ✨ Features
- 🔍 Search for cities
- 🌡️ Celsius and Fahrenheit conversion
- 🌤️ Current weather conditions
- 📅 Hourly and 5-day forecasts
- 💧 Humidity, wind speed, and pressure
- 📱 Responsive design

## 🛠️ Technologies
- HTML
- CSS
- JavaScript
- Open-Meteo API

## 🚀 How to Run
Open `index.html` in your browser.
